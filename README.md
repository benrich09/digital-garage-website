# Smart Garage

TypeScript React + Vite + Tailwind landing site.

## Structure

```
src/
  App.tsx
  components/  Navbar, Footer, PageHero, StoreButtons
  pages/       Home, HowItWorks, Owners, Providers, Download, Register
  data/        services.ts
  i18n/        translations.ts, LanguageContext.tsx
```

## Run

```bash
npm install
npm run dev
```

Language: EN / SW dropdown in the navbar (🇬🇧 🇹🇿).
